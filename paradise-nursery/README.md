# Paradise Nursery

Paradise Nursery là ứng dụng giỏ hàng cho cửa hàng cây cảnh trong nhà, xây dựng bằng React và Redux Toolkit.

## Tính năng
- Trang chủ (Landing page) có nút "Get Started"
- Trang danh sách sản phẩm: 3 danh mục, mỗi danh mục 6 cây
- Nút "Add to Cart" (bị vô hiệu hóa sau khi thêm), biểu tượng giỏ hàng hiển thị tổng số lượng
- Trang giỏ hàng: tăng/giảm số lượng, xóa cây, tổng tiền, Checkout ("Coming Soon"), Continue Shopping
- Thanh điều hướng: Home, Plants, Cart

## Chạy dự án
```
npm install
npm run dev
```
